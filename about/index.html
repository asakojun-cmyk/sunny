このサイトについて

「わからない」を持ち寄って、「わかった！」に変える場所 — キャリコン学びピクニックは、忙しい人が静かに学べる小さな図書室を目指しています。

更新日: 2026年7月11日

はじめまして。こんなサイトです

「キャリコン学びピクニック」は、キャリアコンサルタントという仕事が気になった人が、最初に読む場所です。3児の母が、いま実際に養成講習を受けながら作っています。

いいところだけを書くつもりはありません。独占業務がないことも、5年ごとに更新の費用と時間がかかることも、年収の数字の読み方がややこしいことも、一次情報で確認して、そのまま書いています。読んだ結果「やめておこう」となるなら、それでいいと思っています。35万円と150時間を使う前に気づけたほうが、ずっといいからです。

そのうえで進むと決めた人のために、費用の下げ方、学校の選び方、そして試験勉強の中身まで、ぜんぶ無料で置いてあります。163のことば辞典、66人の理論家、859問の1問1答。運営者が受講中に「分からなかった」ものを、そのつど調べて書きためたものです。

コンセプトは、「わからない」を持ち寄って、「わかった！」に変える。
疲れた日は、閉じても大丈夫。ここはいつでも開いています。

このサイトの方針

  • 難しい専門用語を「ひとこと」「身近なたとえ」「試験で必要な正式な説明」の3段階で解説します。簡単な説明で終わらせず、試験で使える正確な知識につなげます。
  • 学校の情報は「公式情報」「受講者本人の体験」「運営者の考察」を分けて表示します。受講していない学校について「受講体験」とは書きません。
  • 体験談の本文はAIで作りません。運営者本人の記録だけを掲載します。
  • 法律・統計・受験制度・受講料・給付金・合格率などは、一次資料で確認できない内容を推測で公開しません。確認できない項目は「未確認」「調査中」と表示します。
  • 「人気」「一番」「最安」「合格しやすい」などの表現は、客観的な根拠がない場合は使いません。
  • 広告・PRを含む記事には、記事冒頭の分かりやすい場所にPR表示をします。学校からの報酬・無償提供・紹介リンクの有無を記事ごとに開示します。

それぞれの場所で、できること

学校えらびの案内所 養成講座って、どう選ぶの? 費用・期間・オンラインの有無を並べて確認できます。受講中の運営者が、申し込み前に確認したいことも書いています。 資格取得を考えている学校を比較したい費用・給付金が気になる 案内所へ行く → キャリア図書館 キャリア理論や相談に役立つ「ことば」を、ざっくりわかる説明から学べる場所です。 理論を学びたい用語の意味を知りたい検索して調べたい 図書館へ行く → ピクニック広場 キャリア理論家の先生たちとお弁当を食べながら、雑談のように理論を学べる広場です。 理論家に会いたい楽しく学びたいお話で覚えたい 広場へ行く → 試験対策テント キャリアコンサルタント試験の学科・論述・面接対策と、あそんで覚えるミニゲームがあります。 学科試験の対策論述・面接の準備ゲームで覚えたい テントへ行く → キャリア相談テント キャリアコンサルタントの仕事・倫理・守秘義務など、「支援する人」の心がまえを知る場所です。 キャリコンの仕事を知りたい倫理を学びたい テントをのぞく → キャリコンNOW掲示板 労働法・統計・制度など、試験に出る「今」の情報をのぞける掲示板です。 時事・統計が苦手法律を整理したい 掲示板を見る → キャリアマルシェ 資格を取ったあとの働き方や、キャリアコンサルタントの活躍の場に出会えるマルシェです。 資格取得後を知りたい働き方を探したい マルシェを見る → ひと休みの森 ゆっくり休憩したり、運営者のコラムなどの読み物を楽しめる森です。疲れた日は、ここでひと休み。 ちょっと疲れた読み物を楽しみたい 森へ行く →

この学びピクニックが生まれた背景

このサイトは、国家資格キャリアコンサルタントの養成講座で学んでいる運営者が、難しい専門用語をもっと分かりやすく整理したいと思い、制作しています。

私自身も、養成講座を選ぶときには、たくさんの不安がありました。——授業についていける？　仕事や子育てと両立できる？　ロールプレイは難しい？　受講料に見合う内容？

実際に受講して分かったことや、受講前に知りたかったことを、受講者の目線でまとめています。
