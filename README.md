## CSSのまとめ（表示速度のため・2026-10-16〜）

- 各ページは `css/cb-<ハッシュ>.css` という「まとめCSS」を読み込みます。中身は `data-src` に書いてある元のCSS（`css/style.css` など）を順番どおりにつなげて軽くしたものです。
- 見た目を直すときは、これまでどおり元のCSS（`css/○○.css`）を直してください。直したら `python3 scripts/build-css.py` を実行すると、まとめCSSが作り直されます（mainにpushすると GitHub Actions でも自動で作り直されます）。
- 画像は `.webp` を使います（元の `.png` / `.jpg` は残してあります）。
