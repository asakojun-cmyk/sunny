ESSAY MOCK EXAM

論述試験の模擬試験全16回・50分・自動採点つき

事例記録を読んで、設問1〜4に答える。本番と同じ形、同じ時間、同じ行数で書く練習ができます。

キャリアコンサルティング協議会の形式です。JCDA(日本キャリア開発協会)で受ける方は、論述の形がちがいます(逐語記録を読んで答える形)。JCDAの過去問題で練習してね。

モヤン論述って、何を書けばいいのか分からなくて、いつも手が止まっちゃうんだ……。

サニー先生大丈夫。設問ごとに、書くことは決まっているよ。主訴、下線Bの意図、問題とその根拠、これからの方針。50分で書いてみて、どこが抜けているかを確かめよう。

  • 50分本番と同じ制限時間
  • 設問4つ50点満点・目標30点
  • 全16回20代〜50代の16の事例
  • 無料登録はいりません

採点で見る、4つの柱

設問は1〜4の4つです。設問3だけは「①問題」と「②その根拠」の2つに分かれていて、その中に「思い込み」と「見立て」の2つを書きます。このサイトの採点では、設問1・3・4の中身を、次の4つの柱に分けて見ます。

  1. 設問1主訴

    相談者が、この面談で相談したいこと。相談者のことばでまとめます。

  2. 設問3 (a)相談者の思い込み

    確かめていないのに「〜に違いない」「〜しかない」と決めていること。①問題に書き、②根拠で発言を引用します。

  3. 設問3 (b)キャリコンの見立て

    足りていない理解や情報は何か。これも①問題に書き、②根拠で発言を「 」で引用します。

  4. 設問4今後の方策・展開

    思い込みと見立てのそれぞれに、支援を1つずつ。決めるのは相談者です。

設問2(下線Bの応答の意図)は、柱とは別に、設問2として採点します。

相談をえらぶ

どの相談から始めても大丈夫です。書きかけの解答も、採点した記録も、この端末に保存されます。

    これまでの記録

    採点した解答は、自動で残ります。「ふり返る」を押すと、そのときの解答・採点・解説をもう一度見られます。

      記録は、いま使っているこの端末の、このブラウザの中に保存されます(新しい順に40件まで)。別の端末や別のブラウザでは見られません。ブラウザの閲覧データを消したときや、プライベートブラウズ(シークレット)の窓では、残りません。

      公式の資料で、確かめたこと

      この模擬試験は、キャリアコンサルティング協議会が公開している資料に合わせて作っています。

      形式
      記述式4問。事例記録を読み、設問ごとに解答用紙に書く。試験時間は50分。
      配点
      設問1が10点、設問2が10点、設問3が20点(①問題10点・②その根拠10点)、設問4が10点。合わせて50点。
      解答用紙
      設問1は2行、設問2は2行、設問3は①2行・②3行、設問4は6行。行の外や裏面に書いたものは採点されない。字数の指定はない。
      筆記具
      黒の鉛筆かシャープペンシルと、消しゴム。ペンで書いた解答は採点されない。時計は、計時だけの腕時計を自分で持っていく。
      合格基準
      実技(論述50点＋面接100点)の150点満点で、90点以上。そのうえで、論述は配点の40%(20点)以上が必要。
      平均点
      論述の平均は、第30回が31.9点、第31回が32.7点、第32回が32.2点。
      解答
      模範解答と採点基準は、公開されていない。

      出典: キャリアコンサルティング協議会の受験概要、過去問題(第30〜32回の実技・論述)、試験結果、よくある質問。2026年10月13日に確認しました。形式は変わることがあるので、受験する回の案内を必ず確かめてください。

      はじめる前に

      • 1行は、40字で数えています。解答用紙に字数の決まりはないので、これはこのサイトの目安です。字の大きさによって、書ける量は変わります。
      • 事例はすべて、このサイトで作った架空の相談です。過去問題の転載ではありません。相談者の絵は、イメージです(本番の問題用紙に、絵はありません)。実際の過去問題は、試験機関の公式サイトで読めます。
      • 採点は、公式の基準ではありません。書き方の形ではなく、中身を見ます。解答に入っていることばと、解答例との近さを、機械で確かめています。言い回しがちがって×になったときは、自分で直せます。解答例も、このサイトの案です。
      • 事例には、マーカーが引けます。文をなぞると線が引け、色は2つ使えます。本番で使えるのは黒の鉛筆かシャープペンシルだけなので、当日は鉛筆で線を引くことになります。
      • 本番は手書きです。入力よりも時間がかかります。型に慣れたら、紙に書いて50分で書き切る練習もしてください。

      運営者のちゃんより

      わたしも、11月1日に論述を受けます。

      作る前に、試験機関の公式サイトで、過去問題と解答用紙を確かめました。解答用紙は、設問1と設問2が2行ずつ、設問3が5行、設問4が6行。行の外に書いた分は、採点されません。

      だからこの模擬試験は、たくさん書けた人ではなく、短く、的をしぼって書けた人に点が出るようにしています。少し厳しめです。いっしょに練習しましょう。

      残り50:00

      採点しますか？

      採点すると、この回の解答は書き直せなくなります。

      論述対策のポイント

      どの回にも使える、6つのポイントです。次の相談を解く前に、1つだけ選んで意識してみてください。

      書き出しの型を、印刷して手元に置きたい方は論述の型ノート(無料PDF・7ページ) ▶︎

      モヤンぼく、知っていることを全部書こうとして、いつも行が足りなくなっちゃうんだ……。

      サニー先生全部は書かなくていいんだよ。4つの柱に1つずつ、事例のことばで答える。それだけで、行はちょうど埋まるからね。

      1. 書ける量は、思っているより少ない

        解答用紙は、設問1と設問2が2行ずつ、設問3は①が2行・②が3行、設問4が6行です。行の外に書いた分は採点されません。「何を書くか」より先に、「何を書かないか」を決めます。事例の説明を長く写すと、それだけで行が終わります。

      2. 50分の使い方を、先に決めておく

        設問3は①と②を合わせて20点で、いちばん大きい設問です。ここに時間を残せるように、読む時間と見直しの時間を先に決めておきます。下は、時間の分け方の一例です。時計は自分の腕時計で見ます。

        • 読む8分
        • 設問16分
        • 設問26分
        • 設問314分
        • 設問411分
        • 見直し5分

      3. 設問1(主訴)は、最後の発言から

        公式の過去問題では、3回とも、相談者の最後のことばが「どうしたらいいのか分からない」という形の迷いで終わっていました。主訴は、そこを中心にまとめます。キャリコンから見た見立て(自己理解が足りない、など)は、設問1には書きません。

        〜という状況で、〜と感じている。〜するか〜するか、どうしたらよいか相談したい。

      4. 設問2は、「何を受け止め、何に気づいてほしいか」

        公式の過去問題では、3回とも、下線Bは質問ではなく、相談者の気持ちや考えを言いかえて返す応答でした。「励ますため」「アドバイスするため」とは書きません。受け止めた中身と、その先のねらいを書きます。

        〜という思いを受け止めて伝え返し、相談者が〜に気づけるよう促すため。

      5. 設問3は、「思い込み」と「足りないもの」を1つずつ

        ①問題には、(a)思い込みを1つ、(b)足りていない理解や情報を1つ。2行に収めます。②根拠は、相談者の発言を言いかえずに「 」で引用し、①と同じ(a)(b)の記号をつけてそろえます。「〜に違いない」「〜しかない」「聞いていない」「話していない」が目印です。事例に書かれていないことは、足しません。

        ①問題 (a)〜という思い込みがある。(b)〜の理解(情報)が不足している。
        ②根拠 (a)「〜」と述べているため。(b)「〜」と述べているため。

      6. 設問4は、出題範囲の順番で書く

        公式の出題範囲では、相談の進め方が「関係づくり → 自己理解 → 仕事理解 → 意思決定 → 方策の実行」の順に並んでいます。この順で、設問3の思い込みと見立てに、支援を1つずつ対応させます。出題範囲には「最終的な意思決定は相談者自身が行う」とあります。「すすめる」「説得する」は書きません。

        まず〜を受け止め、信頼関係を築く。次に〜を振り返り、〜を深める。そのうえで〜を確かめることを支援し、相談者が納得して自分で決められるよう支援する。

      設問の形・配点・解答用紙の行数・出題範囲は、キャリアコンサルティング協議会の公開資料にもとづいています。書き出しの型、時間の分け方、1行40字という数え方、解答例、採点の観点は、キャリコン学びピクニックの案です。公式の採点基準ではありません。養成講習のテキストや講師の指導とちがうときは、そちらを優先してください。

      • 論述の型ノート(PDF)設問1〜4の書き出しの型と、振り返りシート。印刷して使えます
      • 論述ボードゲーム主訴 → 見立て → 方針を、すごろくで1マスずつ
      • 公式の過去問題協議会のサイトで、直近3回の問題と解答用紙が読めます
