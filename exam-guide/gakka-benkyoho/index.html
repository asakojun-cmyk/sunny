キャリコン学科試験の効率的な勉強法 — 問題番号でわかる出題傾向と対策

過去問3回分(第30〜32回)を1問ずつ確かめて、「何番に、どの分野が出るか」を表にまとめました。

更新日: 2026年10月2日

結論:過去問を解いて、落としやすい分野を補強する

キャリアコンサルタントの学科試験は、全50問・四肢択一のマークシート方式です。試験時間は100分で、100点満点(1問2点)のうち70点以上で合格です。

効率よく勉強するコツは、過去問を解いて、自分が落としやすい分野を見つけ、そこを集中して補強することです。

学科試験は、国が決めた出題範囲の順番に沿って出題されます。そのため、問題番号を見れば、どの分野の問題かがだいたいわかります。番号は回によって2〜3問前後しますが、流れは毎回ほぼ同じです。

サニー先生

問題の並びは「出題範囲」の順番どおりなんだ。だから、間違えた問題の番号を見れば、苦手な分野がわかるよ。

弱点を克服する3ステップ

ステップ1:直近の過去問(3〜5回分)を、本番どおり100分で解く

最初は解けなくても大丈夫です。今の実力と、試験の雰囲気をつかみましょう。過去問は、キャリアコンサルティング協議会のサイトで無料で公開されています。

ステップ2:間違えた問題を「分野ごと」に数える

上の表を使って、間違えた問題がどの分野に多いかを数えます。「理論で3問」「労働市場で4問」のように数えると、弱点がはっきり見えます。問題番号は回によってずれるので、番号ではなく分野で数えるのがおすすめです。

ステップ3:苦手な分野にしぼって補強する

  • 統計・白書が苦手な人:「労働経済の分析」「能力開発基本調査」の概要版で、数字の傾向(増えたか・減ったか)を押さえる。
  • 法律・制度が苦手な人:数字と「義務か努力義務か」を中心に、整理ノートを作る。
  • 相談の技能が苦手な人:相談の流れ(関係づくり → 問題の把握 → 目標設定 → 方策の実行 → 評価・終了)を図にして、各段階でやることを書き出す。
  • 倫理が苦手な人:「キャリアコンサルタント倫理綱領」を一度通して読む。

このサイトで補強するなら

  • 理論家が苦手なら → 理論家図鑑
  • 用語・制度・法律が苦手なら → ことば図鑑と労働法・統計・制度
  • すきま時間に確認したいなら → 1問1答ドリル
  • 白書・調査・報告書を押さえたいなら → 試験に出る資料の要点
  • 出題範囲の全体を見たいなら → 出題範囲と、このサイトの対応表
  • 合格率や試験のしくみを知りたいなら → 試験の難易度と合格率
