理論家図鑑

キャリコン試験の理論家の覚え方
名前が混ざらなくなる4つの手順

スーパーとシャイン、エリクソンとレビンソン。理論家は、覚えたそばから混ざっていきます。覚える量を増やす前に、覚える順番を変えてみませんか。理論家図鑑の66人を、4つの手順で整理しました。

更新日: 2026年10月7日

モヤン

66人もいるの……? 1人目から順番に覚えていたら、10人目で最初の人を忘れちゃったよ。

サニー先生

全員を同じ力で覚えなくていいんだよ。よく出る人から、流れごとに、ちがいで覚えていこう。

4つの手順

理論家が混ざるのは、1人ずつバラバラに、同じ重さで覚えようとするときです。次の順番で進めると、覚える量が小さく分かれます。

  1. よく出る12人から始める(名前とキーワードを、1つずつ)
  2. 6つの流れで束ねる(どの流れの人かを先に知る)
  3. 混ざりやすいペアを、ひとことで見分ける
  4. 問題を解いて、思い出す

試験まで時間がない方は、手順1と手順3だけでも進められます。

手順1:よく出る12人から始める

理論家図鑑では、出題ひんどのめやすを、雲のマークで示しています。いちばん多い「よく出る」は、66人のうち12人です。最初は、この12人だけにしぼります。

覚えるのは、名前と、キーワードを1つ。名前を見たら、キーワードが口から出る状態をめざします。

  • スーパー — キャリア発達理論(キャリア・レインボー)
  • ロジャーズ — 来談者中心療法
  • クランボルツ — 計画された偶発性
  • シャイン — キャリア・アンカー
  • バンデューラ — 自己効力感
  • ホランド — 6つのタイプ(RIASEC)
  • シュロスバーグ — 転機と4つのS
  • サビカス — キャリア構築理論
  • パーソンズ — 特性因子理論(職業指導の父)
  • エリクソン — 8つの発達段階
  • レビンソン — 人生の四季
  • アイビイ — マイクロカウンセリング

2つ目のキーワードや、くわしい中身は、名前を押した先のページにあります。12人が言えるようになってから、「ときどき出る」人へ広げましょう。

※ 出題ひんどは、受験対策で定番とされる度合いをもとにした、運営者調べの目安です。

手順2:6つの流れで束ねる

養成講習では、理論を6つの大枠に分けて習います。理論家を1人ずつ覚えるかわりに、「この人は、どの流れの人か」を先に押さえると、66人が6つの束になります。

  • 精神力動論 — 本人が気づいていない心の動き。
    フロイト → ユング、アドラー、アンナ・フロイト、ボーディン
  • 発達論 — 人は生涯を通じて変わり続ける。
    エリクソン → ハヴィガースト、スーパー、サビカス
  • 自己成長論 — その人自身が持つ、成長する力。
    フッサール → マズロー、ロジャーズ、ハンセン
  • 認知行動論 — 行動と、出来事の受けとめ方。
    パブロフ → スキナー、バンデューラ、クランボルツ
  • 特性因子理論 — 自分と仕事の、合うところ。
    パーソンズ → ホランド、ゴットフレッドソン、ロー
  • 組織心理論 — 組織の中で人はどう働き、どう育つか。
    テイラー → シャイン、ハーズバーグ、ブリッジス

新しい理論家に出会ったら、まず「6つのうち、どれか」を確かめます。流れがわかると、問題文のキーワードから、候補を数人にしぼれます。

サニー先生「理論家の名前」より先に、「流れ」が見えたら大成功だよ。

▶︎ キャリア理論の系譜(似顔絵でたどる6つの流れ)

相談の技法(ロジャーズ・エリスなど)の流れは、カウンセリング理論の系譜にまとめています。

手順3:混ざりやすいペアを、ひとことで見分ける

混ざるのは、たいてい、同じテーマを扱う2人か3人です。1人ずつ覚え直すより、「どこがちがうか」をひとことで言えるようにします。

  • 人生全体か、組織の中か
    スーパーは、人生全体の発達段階と役割。シャインは、組織の中のキャリアと、キャリア・アンカーです。
  • 心理学の理論か、キャリアへの応用か
    バンデューラは、自己効力感やモデリングという、心理学の学習理論そのもの。クランボルツは、それをキャリアの意思決定に応用した人です。
  • 4つのSか、3段階か、4段階のサイクルか
    同じ「転機」でも、シュロスバーグは4つのS(状況・自分・支え・戦略)で資源を点検します。ブリッジスは「終わり→中立圏→始まり」の3段階。ニコルソンは「準備→遭遇→順応→安定化」のサイクルです。
  • 8段階か、四季か、6段階か
    エリクソンは、生涯全体を8段階(心理社会的課題)で。レビンソンは、成人期を四季(安定期と過渡期)で。ハヴィガーストは、6段階の、生活上の具体的な課題で捉えました。
  • 源流か、6タイプか、6段階のカウンセリングか
    マッチングの考え方の元祖がパーソンズ(3要素)。ホランドは、6タイプの類型論(RIASEC)に発展させました。ウィリアムソンは、カウンセリングの技法(6段階)に体系化した人です。
  • プロティアンか、物語か
    どちらも、変化の時代の新しいキャリア論です。ホールは「プロティアン(変幻自在)・心理的成功」、サビカスは「キャリア構築・ライフテーマ・物語」。
  • 虹か、キルトか
    役割の話で混ざりやすい2人です。虹(レインボー)ならスーパー、キルトならハンセン。
  • ABC理論か、自動思考か
    どちらも、考え方を扱います。ABC理論・論駁・「ねばならない」ならエリス。自動思考・スキーマ・うつの治療ならベック。
  • 階層表か、4段階か、カップの絵か
    マイクロ技法の階層表ならアイビイ。ヘルピングの4段階(かかわり〜手ほどき)ならカーカフ。コーヒーカップ・モデルなら國分康孝です。
  • 5段のピラミッドか、2本立てか
    同じ動機づけの話でも、5段のピラミッドはマズロー。満足要因と不満足要因の2本立てはハーズバーグです。
  • 受け身の反応か、自分から動いた結果か
    パブロフは、刺激に対して受け身に起こる反応。スキナーは、自分から行動した結果で変わる行動を扱います。他人を見て学ぶこと(観察学習)を重視したのは、バンデューラです。

ここにないペアは、それぞれの理論家のページにある「混同しやすい理論家」の欄で確かめられます。

モヤン「虹ならスーパー、キルトならハンセン」。これなら、ぼくでも言える!

手順4:問題を解いて、思い出す

読んで「わかった」と思っても、問題になると名前が出てこないことがあります。読む時間の一部を、思い出す時間にまわしましょう。どれも、登録なしで使えます。

  • 理論家カードあわせ — 名前とキーワードを結ぶ、3分のゲームです。手順1の確認に。
  • 理論家の流派仕分けゲーム — 理論家を、流れごとに仕分けます。手順2の確認に。
  • 1問1答(理論家の問題だけ) — 試験の形で問われたときに、選べるかを確かめます。
  • 1問1答(まちがえた問題だけ) — まちがえた問題だけを、あとから解き直せます。

語呂合わせは、使わないの?

このページには、語呂合わせをのせていません。語呂は、名前とキーワードを結ぶ助けになります。ただ、試験で迷うのは「似た2人のどちらか」という場面で、そこで効くのは、ちがいを言えることだと考えているからです。

まず、流れと、ちがいで覚える。それでも残った数人にだけ、自分の言葉で語呂を作る。この順番をおすすめします。
