キャリア理論の系譜

理論家の名前をひとりずつ覚えるより、「キャリアの見方がどう広がってきたのか」を図でたどってみよう。

モヤン

理論家が多すぎて、ごちゃごちゃになってきたよ〜。

🖐️ 名前をタップすると、その理論家の解説ページに飛べます

このページはキャリアの見方がどう広がってきたかの系譜です。相談の技法そのものの流れはカウンセリング理論の系譜にまとめています。エリクソンとバンデューラは、両方の系譜に登場します。

そもそも、この2つは何が違うの?

キャリアコンサルタントの勉強では、性質の違う2種類の理論が出てきます。試験でも「キャリアに関する理論」と「カウンセリングに関する理論」は、別々の項目として定められています。

キャリア理論

「その人に、何が起きているのか」

人はどうやって職業を選び、人生の中でどう変化していくのかを説明する理論です。相談者を理解するための地図にあたります。

パーソンズ / ホランド / スーパー / クランボルツ / シュロスバーグ / サビカス など

カウンセリング理論

「その人と、どう関わるのか」

相談の場で、どう聴き、どう言葉を返すかという関わり方と技法の理論です。実際に相談をするための道具にあたります。

フロイト / ロジャーズ / エリス / ベック / アイビイ など

キャリアコンサルタントは、この両方を使います。キャリア理論で相談者の状況を理解し、カウンセリング理論でその人と向き合う、という組み合わせです。だから2つの系譜を分けて、それぞれたどっていきます。

1900年代〜1950年代ごろ ・ キャリア理論のはじまり

①特性・因子理論

🌱 マッチング

「自分に合う仕事って、どうやって探す?」

この時代は…工業化・都市化が進み、たくさんの人が仕事を求めて都市へ。仕事の種類も急に増え、「何を選べばいいか分からない」人があふれました。

だから…まず自分を知り、次に仕事を知り、その両方を照らし合わせる、という考え方が生まれました。

パーソンズ 自己理解×仕事理解 ホランド RIASEC・六角形

🔗 パーソンズが始めた「人と仕事を合わせる」考えを、ホランドが検査(VPI)として実用化しました。

1950年代〜1980年代ごろ ・ 見方が広がる

②発達理論

🌿 生涯プロセス

「人って、ずっと同じじゃないよね?」

この時代は…戦後の経済成長で、一つの会社に長く勤めるのが当たり前に。寿命も延び、「働く年数」がぐっと長くなりました。

だから…キャリアを「就職する一瞬」ではなく、「人生を通して続いていくもの」として見る視点が広がりました。

スーパー ライフ・キャリア・レインボー エリクソン 8段階の発達課題 ハヴィガースト 6段階の発達課題

🔗 スーパーは、のちのサビカス・ハンセン(④)へつながります。エリクソン(8段階)とハヴィガースト(6段階)は、発達課題の代表として並び称されます。

1970年代〜1990年代ごろ ・ 行動と偶然に注目

③意思決定・学習理論

🎈 行動と偶然

「予定外の出来事も、キャリアになるの?」

この時代は…経済の先行きが揺らぎ、「計画どおりに進むキャリア」が当たり前ではなくなってきました。

だから…偶然の出来事にどう反応し、そこから何を学ぶか、という「行動」に目が向けられるようになりました。

バンデューラ 自己効力感 クランボルツ 計画的偶発性

🔗 バンデューラの心理学の理論(自己効力感・モデリング)を土台に、クランボルツがキャリアへ応用しました。

1980年代〜現代 ・ 転機を物語として見る

④転機・構成主義理論

📖 転機と物語

「経験を、自分はどう意味づける?」

この時代は…終身雇用がゆらぎ、転職・独立・働き方の変化が当たり前に。決まった一本道が、誰にでもあるとは限らなくなりました。

だから…用意された道をたどるのではなく、自分の経験に自分で意味を与えていく、という見方が重視されるようになりました。

シュロスバーグ 4Sシステム サビカス キャリア構成理論 ハンセン 統合的人生設計

🔗 サビカスはスーパー(②)の弟子。ハンセンもスーパーの役割理論を受けつぎ、多様性の視点を加えました。

🌳 ここまでの道のりをおさらい

「理論家の名前」だけでなく、どんな問いからキャリアの見方が広がったのかを眺めてみよう。

ステップ主な理論家キーワードキャリアの見方

3. 行動・学習クランボルツ・バンデューラ計画的偶発性・自己効力感行動や学習、偶然の出来事もキャリアにつながる
