理論の系譜

養成講習で習う6つの大枠ごとに、「誰の理論から、誰の理論が生まれたのか」を似顔絵でたどれます。タブで切り替えてください。

モヤン

理論家が多すぎて、ごちゃごちゃになってきたよ〜。

🖐️ 名前をタップすると、その理論家の解説ページに飛べます

このページはキャリアの見方がどう広がってきたかの系譜です。相談の技法そのものの流れはカウンセリング理論の系譜にまとめています。エリクソンとバンデューラは、両方の系譜に登場します。

そもそも、この2つは何が違うの?

キャリアコンサルタントの勉強では、性質の違う2種類の理論が出てきます。試験でも「キャリアに関する理論」と「カウンセリングに関する理論」は、別々の項目として定められています。

キャリア理論

「その人に、何が起きているのか」

人はどうやって職業を選び、人生の中でどう変化していくのかを説明する理論です。相談者を理解するための地図にあたります。

パーソンズ / ホランド / スーパー / クランボルツ / シュロスバーグ / サビカス など

カウンセリング理論

「その人と、どう関わるのか」

相談の場で、どう聴き、どう言葉を返すかという関わり方と技法の理論です。実際に相談をするための道具にあたります。

フロイト / ロジャーズ / エリス / ベック / アイビイ など

キャリアコンサルタントは、この両方を使います。キャリア理論で相談者の状況を理解し、カウンセリング理論でその人と向き合う、という組み合わせです。だから2つの系譜を分けて、それぞれたどっていきます。

大枠ごとに、誰から誰へ発展したかを見る

心の奥にある、本人も気づいていない動きに注目する流れ。すべての源流にフロイトがいて、ここから多くの理論が枝分かれしました。

1890年代〜 ・ ウィーン

この時代は…原因の見あたらない身体の不調に、医師たちが手を焼いていました。「体は悪くないのに、なぜ症状が出るのか」が説明できなかったのです。

だから…フロイトは「本人が意識できない心の領域(無意識)が症状をつくる」と考えました。人の行動を、自覚していない動機から読みとく見方がここで生まれます。

フロイト精神分析の創始者
無意識という考え方から、5つの方向へ枝分かれ
ユング分析心理学アドラー個人心理学ブリル米国へ紹介アンナ・フロイト防衛機制パールズ→自己成長論へ

精神分析の考え方を職業選択と相談関係に応用したのがボーディンです。カウンセラーと相談者の「作業同盟」は、いまのキャリア相談の共通言語になりました。

ボーディン作業同盟
アンナ・フロイトに学んだエリクソンが、精神分析を「生涯の発達」へ広げる
エリクソン→ 発達論へ

✏️ ここだけ覚えよう！

  • フロイトから枝分かれした5人は「ユ・ア・ブ・ア・パ」。ユング(分析心理学)・アドラー(個人心理学)・ブリル(米国へ紹介)・アンナ(防衛機制)・パールズ(ゲシュタルト療法)。
  • ユング=人生の後半・中年期、アドラー=劣等感と補償・勇気づけ。2人はセットで出るので、キーワードで切り分けます。
  • ボーディンの「作業同盟」は精神力動の人なのにキャリア相談の言葉。ここが引っかけになりやすいポイントです。

「人は生涯を通じて変わり続ける」と考える流れ。エリクソンから始まり、やがてスーパーのキャリア発達理論へつながります。

1950年代〜 ・ 戦後のアメリカ

この時代は…経済成長で一つの会社に長く勤めるのが当たり前になり、寿命も延びました。「働く年数」がぐっと長くなったのです。

だから…キャリアを「就職するその一瞬」ではなく「人生を通してずっと続くもの」として見る視点が必要になりました。発達段階という考え方が、子どもから大人へ、そして職業へと広がります。

エリクソン8つの発達段階
同じころ、子どもがどう育つかの研究も進む
ピアジェ認知発達の4段階ヴィゴツキー発達の最近接領域ボウルビィ愛着(アタッチメント)
「発達」の視点が、大人になってからの一生へ広がる
ハヴィガースト6段階の発達課題レビンソン人生の四季ブロンフェンブレナー環境の層

ビューラーはエリクソンより早い1930年代に「人生全体を段階で捉える」見方を示した先駆者。この見方が、次のキャリア発達理論の土台になりました。

ビューラー生涯発達の先駆(1930年代)
発達の視点が「職業」に持ち込まれ、キャリア理論が生まれる
ギンズバーグ職業発達の先駆
ギンズバーグの見方を受けつぎ、大きく育てた
スーパーキャリア・レインボー
弟子のサビカスが、ライフテーマの考えを構成理論へ発展させた
サビカスキャリア構成理論

エリクソンのアイデンティティ論を意思決定モデルへつないだのがティードマンです(同じ意思決定理論のジェラット・ヒルトンは「認知行動論」タブ)。キューブラー・ロスが描いた喪失のプロセスは、のちの転機理論(「組織心理論」タブ)とあわせて覚えます。

ティードマン分化と統合キューブラー・ロス死の受容5段階

✏️ ここだけ覚えよう！

  • 段階の数が最頻出。エリクソン8段階／ハヴィガースト6段階／ピアジェ4段階／ギンズバーグ3段階／スーパー5段階。数字が入れかわった選択肢を×にできれば得点源です。
  • スーパーの5段階は成長→探索→確立→維持→解放(下降)。段階のあいだには「ミニサイクル」があります。
  • ピアジェは順番が変わらないのがポイント。感覚運動期→前操作期→具体的操作期→形式的操作期。
  • エリクソンとレビンソンの区別は「8段階か、四季か」で。

「答えはその人の中にある」と考え、本人の体験と成長する力を信じる流れ。いまのキャリア相談の基本姿勢そのものです。

1940〜60年代 ・ アメリカ

この時代は…当時の心理学は、病気を診る精神分析と、行動だけを見る行動主義が中心。「健康な人が本来もっている力」を扱う場所がありませんでした。

だから…「人は自分で成長する力を持っている」と考える第三の流れ(人間性心理学)が起こりました。いまのキャリア相談の「指示せず、聴く」という姿勢は、ここから来ています。

フッサール現象学
「本人の体験に立ち返る」考えが、精神医学に取り入れられる
ビンスワンガー現存在分析ボス現存在分析(臨床)
「人生の意味」「不安と自由」という問いへ広がる
フランクルロゴセラピーロロ・メイ実存療法ヤーロム実存的心理療法

精神分析から出発したパールズのゲシュタルト療法も、「いま・ここ」の体験を重視する点でこの流れに合流します。

パールズゲシュタルト療法
これらの流れが合流し、「第三の勢力」人間性心理学が生まれる
マズロー欲求階層説ロジャーズ来談者中心療法
ロジャーズの流れから、3人がそれぞれの形へ発展させた
ジェンドリンフォーカシングカーカフヘルピング國分康孝コーヒーカップ

マズローの欲求階層説はロー(特性因子理論)へ、ロジャーズの姿勢はハンセンの統合的人生設計へとつながります。

ハンセン統合的人生設計

✏️ ここだけ覚えよう！

  • 第一勢力=精神分析／第二勢力=行動主義／第三勢力=人間性心理学。この並びがそのまま問われます。マズローとロジャーズは並び立つ2本の柱で、どちらかの弟子ではありません。
  • ロジャーズの3条件は自己一致・無条件の肯定的配慮・共感的理解。実技(面接)試験の土台にもなります。
  • マズローの欲求は5段階:生理的→安全→所属と愛→承認→自己実現。
  • ロジャーズから広がった3人はジェンドリン(フォーカシング)・カーカフ(ヘルピング)・國分康孝(コーヒーカップ)。

観察できる行動と、その人の受けとめ方(認知)に働きかける流れ。キャリア理論では「偶然をどう活かすか」につながります。

1900年代〜 ・ ロシア/アメリカ

この時代は…心理学を科学にするには、目に見えない「心の中」ではなく、外から観察できるものを扱うべきだという考えが強まりました。

だから…まず「行動」が研究され、やがて「出来事そのものより、それをどう受けとめるか」という認知にも光が当たります。キャリアでは「偶然をどう活かすか」につながりました。

パブロフ古典的条件づけソーンダイク効果の法則

パブロフとソーンダイクは、ほぼ同じころに別々に学習のしくみを見つけた2つの源流です。どちらかが弟子ということはありません。

「心の中ではなく、行動だけを科学的に扱おう」と宣言される
ワトソン行動主義の宣言
2つの源流を受けつぎ、行動が変わるしくみが実験で体系化される
スキナーオペラント条件づけ
治療技法へ応用される一方、次の世代が乗りこえていく
ウォルピ系統的脱感作法バンデューラ自己効力感
バンデューラの社会的学習理論を、キャリアの意思決定へ応用
クランボルツ計画された偶発性

アイビイのマイクロカウンセリングは、多くの流派の技法を統合して段階的に学べる形に整理したもの。特定の誰かの弟子ではありませんが、技法を「学習する」という点でこの流れに入ります。

アイビイマイクロ技法

別の源流として、出来事の受けとめ方に働きかける認知行動療法の2本柱があります。

エリス論理療法ベック認知療法

転機を実践的な道具(4S)へ落とし込んだシュロスバーグも、この大枠に位置づけられます(比較対象のブリッジス・ニコルソンは「組織心理論」タブ)。

シュロスバーグ4Sシステム

「人はどう考えて決めるのか」に注目した意思決定の理論も、認知に働きかけるこの流れの仲間です(エリクソン由来のティードマンは「発達論」タブ)。

ジェラット連続的意思決定ヒルトン認知的不調和

✏️ ここだけ覚えよう！

  • パブロフ=古典的条件づけ／スキナー=オペラント条件づけ。受け身に条件づくか、自分から行動するか、で区別します。ソーンダイク=効果の法則はパブロフと並ぶもう一つの源流。
  • バンデューラの自己効力感の4つの情報源は最頻出:成功体験・代理的経験・言語的説得・情動的喚起。
  • クランボルツの5つのスキルも頻出:好奇心・持続性・柔軟性・楽観性・冒険心。差し替え問題が定番です。
  • エリス=論理療法(ABC理論・「ねばならない」・論駁)／ベック=認知療法(自動思考・スキーマ)。この区別が最頻出。

「自分を知り、仕事を知り、その両方を合わせる」という、キャリア理論のいちばん古い流れです。

1900年前後 ・ ボストン

この時代は…工業化と都市化で、地方から都市へ人が流れこみました。仕事の種類も急に増え、「何を選べばいいか分からない」人があふれます。

だから…パーソンズが職業指導局をつくり、「まず自分を知り、次に仕事を知り、その両方を照らし合わせる」という手順を示しました。キャリア理論のいちばん古い流れです。

パーソンズ職業指導の父
マッチングの考えを受けつぎ、2つの方向へ発展
ウィリアムソン指示的カウンセリングホランドRIASEC検査へ
ホランドの6角形を、2つの軸で説明し直す
プレディガーワークタスク次元
ホランドの興味理論に、性役割や社会的地位という社会の視点を加える
ゴットフレッドソン限界と妥協

ローは、マズローの欲求階層説(自己成長論)を職業選択に取り入れた人です。

ロー早期決定論

✏️ ここだけ覚えよう！

  • パーソンズの3要素:①自己の特性の理解 ②職業に関する知識 ③両者の合理的な推論(マッチング)。
  • ホランドのRIASEC:現実的・研究的・芸術的・社会的・企業的・慣習的。人と環境の両方を同じ6タイプで見るのがポイントです。
  • ゴットフレッドソンの限界の4段階は年齢とセットで:大きさと力(3〜5歳)→性役割(6〜8歳)→社会的評価(9〜13歳)→内的な自己(14歳〜)。
  • ローは幼少期の親子関係が職業選択に影響。土台がマズローである点もよく出ます。

「組織の中で人はどう働き、どう育つか」を扱う流れ。企業内のキャリア支援に直結します。

1910年代〜 ・ アメリカ

この時代は…工場の生産性をどう上げるかが企業の課題でした。最初は作業を細かく分解して効率を測る方向へ進みます。

だから…やがて「人は機械ではなく、集団の中で動く」ことが分かり、関心は効率から人と集団、さらに組織の中の個人のキャリアへと移っていきました。

テイラー科学的管理法
「効率」から「人と集団」へ関心が移る
レヴィングループダイナミックス
人を動かすものは何かという、動機づけの研究へ
マクレガーX理論・Y理論マクレランド達成動機ハーズバーグ動機づけ・衛生理論ヴルーム期待理論デシ内発的動機づけ
組織の中の個人のキャリアへ、焦点が移る
シャインキャリア・アンカー
シャインらの組織内キャリア研究を、次の世代が受けつぐ
ホールプロティアンバンマーネン組織社会化

転機そのものを扱うブリッジスとニコルソンも、この大枠に位置づけられます(シュロスバーグとの区別が頻出)。

ブリッジストランジションニコルソン転機の4段階

✏️ ここだけ覚えよう！

  • ハーズバーグの二要因は「給与は衛生要因」が定番の引っかけ。動機づけ要因=達成・承認・仕事そのもの・責任・昇進。
  • シャインのキャリア・アンカーは8つ。専門・職能別／全般管理／自律・独立／保障・安定／起業家的創造性／奉仕・社会貢献／純粋な挑戦／生活様式。
  • 転機トリオの区別が頻出:シュロスバーグ=4S(状況・自分・支え・戦略)／ブリッジス=終焉→中立圏→開始／ニコルソン=準備→遭遇→順応→安定化。
  • マクレガーはX理論=なまけ者という人間観／Y理論=自ら進んで働く。
